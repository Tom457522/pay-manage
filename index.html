AIレシート読み取り

Anthropic の API キーを設定すると、Claude がレシートを品目ごとに読み取ります。キーはこの端末のブラウザ内にだけ保存されます。

万一に備え、このアプリ専用のキーを作り、Anthropic Console で月の利用上限を低め（例：$5）に設定しておくことをおすすめします。

AI振り分けルール

PayPay の履歴を取り込んだとき、このルールに沿って AI が負担者（または除外）を自動で選びます。ふたりの端末で共有されます。空欄なら過去の記録だけを参考にします。

データの共有・バックアップ

記録のファイル保存と、同期を使わない場合の受け渡し用です。「読み込み」は記録を統合します（同じ記録は新しい方で上書き）。
